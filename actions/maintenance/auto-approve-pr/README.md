# Maintenance Auto-approve-pr

Auto approve Pull Requests with the given user ids and branches.

[actions-maintenance-auto-approve-pr-v3.0.6](https://github.com/TimSchoenle/actions/releases/tag/actions-maintenance-auto-approve-pr-v3.0.6) · JavaScript action (node24)

## Usage

### Approve Renovate pull requests

```yaml
name: Renovate Auto Approve

on:
  pull_request:
    types: [opened, synchronize, reopened, ready_for_review]

# A newer push supersedes the run that judged the previous head.
concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: true

permissions: {}

jobs:
  auto-approve:
    name: Auto Approve
    runs-on: ubuntu-latest
    # Approving with the job token also needs the repository setting "Allow GitHub Actions to create
    # and approve pull requests".
    permissions:
      pull-requests: write # read the pull request and its commits, and approve it
    steps:
      - uses: TimSchoenle/actions/actions/maintenance/auto-approve-pr@actions-maintenance-auto-approve-pr-v3.0.6 # tag=actions-maintenance-auto-approve-pr-v3.0.6
        with:
          token: ${{ github.token }}
          # Database IDs of the accounts whose pull requests may be approved; 29139614 is Renovate.
          user_ids: '29139614'
          branch_pattern: '^renovate/.*$'
```

## Inputs

| Input                  | Required | Default                                     | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ---------------------- | -------- | ------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `token`                | yes      |                                             | GitHub Token with pull-request: write access.                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `user_ids`             | yes      |                                             | Comma-separated list of Database IDs of accepted accounts (e.g. "29139614, 123456"). The pull request author and every commit author must be one of them, and every commit must carry a valid signature. A commit signed with a personal key must also have an accepted committer, linked to its account, and an accepted key owner. A commit GitHub signed itself skips those two checks: GitHub is its committer, and it resolves to no account. The approval is bound to the head commit that was verified. |
| `ignore_empty_prs`     | no       | `true`                                      | Ignore PRs with 0 changes. Renovate seems to sometimes create multiple lock-files PR without changing anything.                                                                                                                                                                                                                                                                                                                                                                                                |
