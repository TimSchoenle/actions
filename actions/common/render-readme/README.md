# Common Render README

Renders README.md from its Handlebars template with the shared README payload, and either uploads the result as a create-patch artifact or fails when the committed file is stale.

[actions-common-render-readme-v1.1.2](https://github.com/TimSchoenle/actions/releases/tag/actions-common-render-readme-v1.1.2) · Composite action
<!-- /docs:generated header -->

It is the README job every repository repeats, in one step: [`common/readme-variables`](../readme-variables) collects
the payload, [`common/render-template`](../render-template) renders it, and [`common/create-patch`](../create-patch)
uploads the result as a generator patch for [`common/generated-files-verdict`](../generated-files-verdict).

With `check: true` it writes nothing and fails when the committed file is stale: the drift gate for pushes to the
default branch and for forks.

## Usage

### Generator job

```yaml
# A generator job of a repository's Generate workflow.
jobs:
  readme:
    name: README
    runs-on: ubuntu-latest
    permissions:
      contents: read
    outputs:
      has_changes: ${{ steps.readme.outputs.has_changes }}
      artifact_name: ${{ steps.readme.outputs.artifact_name }}
    steps:
      - uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7
        with:
          ref: ${{ github.event.pull_request.head.sha }}
          persist-credentials: false
      - id: readme
        uses: TimSchoenle/actions/actions/common/render-readme@actions-common-render-readme-v1.1.2 # tag=actions-common-render-readme-v1.1.2
```

### Drift gate on the default branch

```yaml
# The drift gate on the default branch. Give it the same inputs as the generator job.
- uses: TimSchoenle/actions/actions/common/render-readme@actions-common-render-readme-v1.1.2 # tag=actions-common-render-readme-v1.1.2
  with:
    check: 'true'
```
<!-- /docs:generated usage -->

Give both the same inputs: the gate reproduces the render and compares, so any difference would pass a stale file.

## Egress

A job that runs `step-security/harden-runner` with `egress-policy: block` has to allow:

| Endpoint                              | For                        |
| ------------------------------------- | -------------------------- |
| `*.actions.githubusercontent.com:443` | the artifact upload API    |
| `*.blob.core.windows.net:443`         | the uploaded patch content |
<!-- /docs:generated egress -->

Neither is reached with `check: true`, which uploads nothing.

## Behaviour

- **`branch` defaults to the default branch, not `github.ref_name`.** On a pull request that is `<number>/merge`;
  rendered into badge URLs, it would make the generator and the drift gate disagree on every merge.
- With an empty `branch` on an event whose payload names no default branch, the step fails and asks for `branch`.
