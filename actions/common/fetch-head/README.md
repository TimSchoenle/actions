# Common Fetch Head

Fetches one commit into an empty repository and points HEAD at it without checking anything out, for steps that read only git objects.

[actions-common-fetch-head-v1.1.1](https://github.com/TimSchoenle/actions/releases/tag/actions-common-fetch-head-v1.1.1) · JavaScript action (node24)
<!-- /docs:generated header -->

<!-- docs:generated usage -->
## Usage

```yaml
- uses: TimSchoenle/actions/actions/common/fetch-head@b37134ffa35b3ce98437447e3b4c76933eb65c04 # tag=actions-common-fetch-head-v1.1.1
  with:
    sha: # required, see Inputs
```

## Inputs

| Input        | Required | Default                    | Description                                                                                                                                                                                                                                                                         |
| ------------ | -------- | -------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `sha`        | yes      |                            | The commit to fetch, as a full 40-character SHA. Any other value fails the step before anything is fetched.                                                                                                                                                                         |
| `repository` | no       | `${{ github.repository }}` | Repository to fetch from, as owner/repo. A pull request from a fork is fetched from the base repository, which serves its head under refs/pull.                                                                                                                                     |
| `token`      | no       | `${{ github.token }}`      | Token sent with the fetch, as actions/checkout sends it, so a private repository can be read. It reaches git through the environment only and is never written to the repository config. Empty fetches anonymously. A token is sent over https only, or plain http to this machine. |
| `path`       | no       | `.`                        | Directory, relative to the workspace, to create the repository in. It must not exist yet or be empty. When git fails, the repository is removed again, so the step can be re-run.                                                                                                   |
| `server_url` | no       | `${{ github.server_url }}` | URL of the GitHub server to fetch from.                                                                                                                                                                                                                                             |
