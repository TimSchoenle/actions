# Create Branch

Creates or resets a git branch using GitHub API.

[actions-common-create-branch-v2.0.4](https://github.com/TimSchoenle/actions/releases/tag/actions-common-create-branch-v2.0.4) · JavaScript action (node24)
<!-- /docs:generated header -->

<!-- docs:generated usage -->
## Usage

### Cut a release branch

```yaml
name: Cut Release Branch

on:
  workflow_dispatch:
    inputs:
      version:
        description: Release line, e.g. 1.4
        required: true

permissions: {}

jobs:
  create-branch:
    runs-on: ubuntu-latest
    permissions:
      contents: write # to create the branch
    steps:
      - id: branch
        uses: TimSchoenle/actions/actions/common/create-branch@7c1147cf1e275c068a8484fa9a2dcb38a8b1f92f # tag=actions-common-create-branch-v2.0.4
        with:
          token: ${{ github.token }}
          repository: ${{ github.repository }}
          branch_name: release/${{ inputs.version }}
          # No base_branch, so the branch starts from the default branch. reset_branch stays false:
          # an existing release branch is left where it is, and created reports false.

      - run: echo "release/${VERSION} is at ${SHA} (created ${CREATED})"
        env:
          VERSION: ${{ inputs.version }}
          SHA: ${{ steps.branch.outputs.sha }}
          CREATED: ${{ steps.branch.outputs.created }}
```
