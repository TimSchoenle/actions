# Rust Clippy

Action that runs clippy to catch common mistakes and improve your Rust code.

[actions-rust-clippy-v2.0.0](https://github.com/TimSchoenle/actions/releases/tag/actions-rust-clippy-v2.0.0) · Composite action
<!-- /docs:generated header -->

<!-- docs:generated usage -->
## Usage

### Lint on every push and pull request

```yaml
# The action checks the repository out itself. Findings appear as annotations on the run.
name: Lint

on:
  push:
    branches: [main]
  pull_request:

permissions: {}

jobs:
  clippy:
    name: Clippy
    runs-on: ubuntu-latest
    permissions:
      contents: read # to fetch code
    steps:
      - uses: TimSchoenle/actions/actions/rust/clippy@actions-rust-clippy-v2.0.0 # tag=actions-rust-clippy-v2.0.0
        with:
          clippy_arguments: '--all-features --all-targets -- -D warnings'
```

## Cache

`actions-rust-lang/setup-rust-toolchain` restores the Rust cache on every run but saves it only on the default branch,
and on a schedule, which always runs there. GitHub scopes a cache to the ref that saved it, so a cache saved from a
pull request could not be restored on the default branch, yet it counted against the repository's cache quota and
evicted the default branch's entries.
